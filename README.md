# PDF 나누기

브라우저에서 PDF를 북마크로 나누거나 여러 PDF를 하나로 합칩니다. 파일은 서버로 전송되지 않고, 이 브라우저 안에서만 처리됩니다.

배포 주소: https://han-ent.github.io/pdf-split/

데스크톱 앱 [pdf-ocr-split-tool](https://github.com/ys-laube/pdf-ocr-split-tool)의 분할·병합을 웹으로 옮긴 것입니다. OCR은 포함하지 않습니다.

## 나누기

1. PDF를 놓습니다.
2. 북마크 단계(레벨)를 고릅니다. 1은 보통 장, 2는 절입니다.
3. 저장할 항목만 체크합니다.
4. PDF 하나면 그대로 저장하고, 여러 개면 ZIP으로 받습니다.

쪽 범위는 데스크톱 앱과 같습니다. 같은 레벨의 다음 북마크 직전에서 끝나고, 같은 쪽을 가리키면 그 쪽으로 맞추며, 마지막 북마크는 문서 끝까지입니다. 파일명에 쓸 수 없는 문자는 `_`로 바꿉니다. 기본값은 `001_제목.pdf`이고, 제목에 번호가 있으면 끌 수 있습니다.

나뉜 파일에는 그 구간의 하위 북마크를 다시 넣습니다. 쪽 번호는 새 파일 기준으로 맞춥니다.

북마크가 없으면 페이지 범위로 나눌 수 있습니다. `10쪽씩` 또는 직접 입력합니다.

```
1-12 1장
13-30 2장
31- 부록
```

## 합치기

PDF를 여러 개 넣은 뒤 손잡이를 끌어 순서를 바꿉니다. 각 파일의 북마크는 페이지를 밀어 한 목차로 잇습니다. 북마크가 없는 파일은 파일 이름으로 항목을 하나 만듭니다.

## 개발

```bash
npm install
npm test
npm run dev
npm run build
```

`npm run sample -- /tmp/pdf-split-sample` 은 북마크가 있는 작은 예시 PDF를 만듭니다. 교재 PDF는 저장소에 넣지 않습니다.

화면 문구는 `src/i18n/ko.ts`에만 있습니다. `Catalog` 타입을 맞추면 다른 언어를 나중에 붙일 수 있습니다.

## 배포

`main`에 푸시되면 GitHub Actions가 테스트를 돌리고 GitHub Pages에 올립니다. 자산 경로는 상대 경로(`./`)라 저장소 이름이 바뀌어도 동작합니다.
